ABSTRACT
A reference implementation is commonly used as the cor-
rectness target for a DSP task. That test is exact when the
specification identifies one realization, but a magnitude mask
defines a feasible set, not one coefficient vector. We ask when
a scalar reference-distance oracle can recover specification
membership on an evaluated universe, and give a finite-
set exactness criterion in terms of a reference-separability
gap. Final labels come from an independent dense-grid ver-
ifier, not the construction checker. On 20 mask instances,
no coefficient-distance threshold separates independently
verified valids from invalids (20/20), including every li-
brary choice of reference and finite reference sets of size
K ∈{1, 3, 5, all}. Same-order, same-structure alternatives
remain reference-discordant on 20/20 tasks.
The gap is
positive on eight singleton identities. Reference agreement
is therefore a realization diagnostic, not a specification or-
acle, on these non-unique tasks.

1. INTRODUCTION
Evaluating a DSP implementation against a trusted reference
is natural when the specification is a unique map: one integer
delay, one Fourier convention, one alias-fold period. In those
cases, agreement with the reference is correctness.
Classical filter design is different. A magnitude mask with
a free transition defines a feasible set of realizations, not a
unique impulse response [1, 2, 3, 4]. Windowed designs [5,
6], frequency sampling [7], equiripple Parks–McClellan ap-
proximation [8, 9, 10], and IIR Butterworth or elliptic sec-
tions [11, 12, 13, 14] can all meet the same passband, stop-
band, and stability bounds. That multiplicity is classical and
is not our claim.
The evaluation question is sharper. A canonical library
call—Hamming firwin, or a Butterworth section [15]—
is one occupant of the feasible set. A test that accepts only
neighbors of that occupant asks whether a candidate is the
same realization. It does not ask whether the candidate meets
the contract that justified the reference. When can a reference-
based scoring rule be a correct oracle for a specification-
defined DSP task?
We formalize the distinction among a reference realiza-
tion, a reference acceptance region, and the specification-
valid set, and give a finite-universe criterion for the existence
of any scalar threshold on distance to that reference. The cri-
terion is not a theorem over all filters: extrema are computed
on an explicitly stated evaluated universe after independent
verification. Related work treats the mask as a feasible-set
design problem [1, 10, 16], uses a golden reference in DSP
testing [17], or scores generated code with unique-output unit
tests [18, 19]. Those protocols do not decide when a reference
ball recovers a non-unique DSP mask.
Contributions. (i) We state soundness, completeness, and
exactness of a reference-distance oracle relative to a speci-
fication, and a finite-set reference-separability gap. (ii) We
separate candidate construction from final labeling with an in-
dependent verifier, and probe same-order Type-I feasible sets
with predetermined directions. (iii) On 20 mask instances the
gap is non-positive in coefficient space for every library ref-
erence and for finite multi-reference oracles; it is positive on
eight singleton identities.
