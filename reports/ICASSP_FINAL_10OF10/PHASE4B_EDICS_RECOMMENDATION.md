# PHASE 4B — EDICS / track recommendation

**Primary:** Signal Processing Theory & Methods

**Secondary:** Applied Signal Processing Systems

Rationale. The paper studies when a realization-reference oracle recovers a FIR/IIR magnitude-mask specification, using continuous band certification, Schur stability, and coefficient versus magnitude-response geometry. That is a SPTM evaluation / theory-of-methods question. The practical consequence is how filter-design test benches should treat golden coefficient vectors versus response surrogates, which is applied DSP systems evaluation. Machine Learning is not an appropriate primary track: generated-code experiments are no longer the paper’s science.
